NFC UPLINK GUIDE · NFC Tools

NFC Tools で、蓋のタグに書き込む。Write the lid’s tag with NFC Tools.

INFINITY のHODLケースは、蓋にNFCタグが入っています。そこへ、ケースごとのコックピットのURLを、無料アプリ「NFC Tools」で書き込みます。iPhone でも Android でも、同じアプリです。Every INFINITY HODL case has an NFC tag in its lid. You write that case’s cockpit URL to it with the free “NFC Tools” app — the same app on iPhone and Android.

02WHERE TO HOLD

かざす位置Where to hold it

厚いケースや金属のケース、カード入れが付いたケースは、外すと反応しやすくなります。かざしたら、1〜2秒は動かさずに。Thick, metal or card-holder phone cases can block NFC — take them off if it won’t respond. Keep still for a second or two.

03WRITE

書き込むWrite the tag

  1. 1

    URLをコピーするCopy the URL

    打ち上げの手順 T−2 の「URLをコピー」を押します。In launch step T−2, tap “Copy URL”.

  2. 2

    NFC Tools を開き、URLのレコードを足すOpen NFC Tools and add a URL record

    書く（Write）→ レコードを追加（Add a record）→ URL / URI の順に押します。Tap Write → Add a record → URL / URI.

  3. 3

    貼り付けて OKPaste and confirm

    入力欄を長押しして貼り付け、OK。最初から「https://」が入っている場合は、二重にならないように直します。Long-press the field, paste, and tap OK. If “https://” is already there, make sure it isn’t doubled.

  4. 4

    書き込むWrite

    書く（Write）を押すと「スキャンの準備ができました」のような画面が出ます。iPhone の上の端を蓋に当て、完了の表示が出るまで動かしません。Tap Write; a “Ready to Scan” style sheet appears. Hold the top edge of the iPhone to the lid until it confirms.

  1. 1

    NFC をオンにするTurn NFC on

    設定アプリで「NFC」を探してオンにします（「接続」「接続済みのデバイス」などの中にあります）。Find “NFC” in Settings and switch it on (usually under Connections or Connected devices).

  2. 2

    URLをコピーするCopy the URL

    打ち上げの手順 T−2 の「URLをコピー」を押します。In launch step T−2, tap “Copy URL”.

  3. 3

    URLのレコードを足して貼り付けるAdd a URL record and paste

    NFC Tools で 書く（Write）→ レコードを追加（Add a record）→ URL / URI。貼り付けて OK。In NFC Tools tap Write → Add a record → URL / URI, paste and tap OK.

  4. 4

    書き込むWrite

    書く（Write）を押し、スマホの背面を蓋に当てて待ちます。反応しなければ、当てる位置を少しずつずらします。Tap Write and hold the back of the phone to the lid. If nothing happens, slowly shift the position.

書き込むレコードは、このURLの1件だけにしてください。iPhone は、タグの最初のURLしか読みません。アプリの表示は、バージョンや言語の設定で少し違うことがあります。Write only this one URL record — iPhone reads only the first URL on a tag. Labels can differ slightly by app version and language.

04TEST

かざして確かめるTap to test

iPhone XS ~

NFC Tools を閉じて、画面をつけたまま蓋にかざします。出てきた通知を押すと、Safari でコックピットが開きます。Close NFC Tools and, with the screen on, hold the phone to the lid. Tap the notification and the cockpit opens in Safari.

カメラや Wallet（Apple Pay）を使っている間、機内モードの間、ほかのアプリでNFCを読んでいる間は反応しません。再起動したあとは、一度ロックを解除してから。It won’t respond while the camera or Wallet (Apple Pay) is in use, in Airplane mode, while another app is reading NFC, or before the first unlock after a restart.

iPhone 7 · 8 · X

コントロールセンターの「NFCタグリーダー」を押してから、蓋にかざします。見当たらないときは、設定のコントロールセンターから追加します。Open “NFC Tag Reader” in Control Center, then hold the phone to the lid. If it’s missing, add it in Settings › Control Center.

ANDROID

NFC をオンにして、画面のロックを解除した状態でかざします。ブラウザでコックピットが開きます。With NFC on and the screen unlocked, hold the phone to the lid. The cockpit opens in your browser.

SUCCESS

コックピットに、あなたが付けた名前と「静寂（STANDBY）」が出れば成功です。打ち上げの手順と同じブラウザなら、上に「UPLINK CONFIRMED」も出ます。If the cockpit shows your case name and “Standby”, it worked. In the same browser as the launch sequence, you’ll also see “UPLINK CONFIRMED” at the top.

05LOCK · OPTIONAL

ロックする（任意）Lock it (optional)

ロックすると、だれもタグを書き換えられなくなります。知らない人に、偽のページへのURLへすり替えられるのを防げます。Locking makes the tag read-only, so nobody can swap in a URL to a fake page.

NFC Tools で その他（Other）→ タグをロック（Lock tag）→ 確認で はい（Yes）を押し、蓋をかざします。In NFC Tools tap Other → Lock tag → Yes, then hold the lid to the phone.

取り消せません。あなた自身も、二度と書き換えられなくなります。必ず「かざして確かめる」が済んでから。This can’t be undone. You won’t be able to rewrite it either. Only lock after the tap test works.

06TROUBLESHOOT

うまくいかないときIf it doesn’t work

タグが反応しないThe tag doesn’t respond

当てる位置をゆっくりずらし、見つかったら1〜2秒止めます。スマホのケースを外すと反応しやすくなります。Android は設定で NFC がオンか確かめます。Slowly move the phone around and hold still for a second or two when it reacts. Removing the phone case helps. On Android, check that NFC is on.

書き込みに失敗するWriting fails

ロック済みのタグには書き込めません。「容量が足りない」と出る場合は、打ち上げの手順 T−3 で名前を短くしてください（キットのタグに入るのは約144バイト）。それ以外は、動かさずにもう一度。A locked tag can’t be written. If it says there isn’t enough space, shorten the name in launch step T−3 (the kit’s tag holds about 144 bytes). Otherwise, hold still and try again.

違うページが開く・何も開かないA different page opens, or nothing opens

レコードが2件以上あると、iPhone は最初のURLだけを読みます。NFC Tools の その他（Other）→ タグを消去（Erase tag）で消してから、URLの1件だけを書き直します。「https://」が二重になっていないかも確かめます。With two or more records, iPhone reads only the first URL. Erase the tag in NFC Tools (Other → Erase tag), then write just the one URL. Also check that “https://” isn’t doubled.

コックピットに「アドレスがありません」と出るThe cockpit says “No address”

URLが途中で切れています。打ち上げの手順に戻って、表示されたURLをそのままコピーし、書き直してください。The URL was cut short. Go back to the launch sequence, copy the URL exactly as shown, and write it again.

iPhone で通知が出ないNo notification on iPhone

画面をつけて、ロックを解除した状態で試します。カメラや Wallet を閉じ、機内モードを切ります。iPhone 7〜X は、コントロールセンターの「NFCタグリーダー」を使います。Try with the screen on and unlocked. Close the camera and Wallet, and turn off Airplane mode. On iPhone 7 to X, use the NFC Tag Reader in Control Center.
