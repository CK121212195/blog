09FAQ

気になることQuestions

ライトニングのsatsですか？Are these Lightning sats?

中身はオンチェーンのビットコインです。ライトニングのウォレットからでも、オンチェーン送金に対応していれば入れられます。It holds on-chain bitcoin. You can fund it from a Lightning wallet too, as long as the wallet supports on-chain sends.

いくら入れればいいですか？How much should I put in?

額は自由です。ただ、あとで移すときにオンチェーンの手数料がかかるため、少額だと手数料の割合が大きくなります。Any amount. Moving it out later costs an on-chain fee, so with very small amounts the fee takes a larger share.

取引所から入金できますか？Can I send from an exchange?

多くの場合できます。自分で管理するウォレット宛ての送金になるため、取引所によっては、送付先の持ち主の情報（本人かどうか・氏名など）の入力や登録を求められます。Usually, yes. Because it’s a withdrawal to a self-custody wallet, some exchanges ask for details about the recipient (whether it’s you, a name, and so on).

iPhoneでも使えますか？Does it work with iPhone?

はい。iPhone XS 以降は、画面をつけた状態で蓋にかざすだけで読めます。iPhone 7〜X は、コントロールセンターの「NFCタグリーダー」から読めます。タグへの書き込みは、iPhone・Android とも NFC Tools アプリで行います。Yes. iPhone XS and later read the tag when you hold it to the lid with the screen on. On iPhone 7 to X, use the NFC Tag Reader in Control Center. Writing the tag is done with the NFC Tools app on both iPhone and Android.

NFC Tools の使い方を見るSee how to use NFC Tools

札をなくしたら？What if I lose the slip?

札の12語や秘密鍵がなければ、だれも中のsatsを動かせません。販売者やこのサイトが取り戻すこともできません。札は大切に保管してください。Without the slip’s 12 words or private key, no one can move the sats inside — and neither the seller nor this site can recover them. Keep the slip safe.

このサイトが無くなったら？What if this site disappears?

タグに書いたURLの中にアドレスが入っているので、NFC読み取りアプリでURLを見れば、どのブロックエクスプローラーでも確かめられます。中のsatsを動かすのに、このサイトは要りません。The address is inside the URL on the tag, so any NFC reader app shows it, and any block explorer can check it. Moving the sats never needs this site.

贈った相手が中身を動かしたら？What if the recipient moves the funds?

承認されるとパッチが「移動後」の姿に変わり、移動したブロックが記録として残ります。贈り主も鍵の控えを持てるため、受け取った方が自分だけで管理したいときは、開けて移すことをおすすめしています。Once confirmed, the patch turns into its released form and the block of the move stays on record. Since a giver could keep a copy of the key, we recommend that recipients who want sole control open it and move the funds.

価格の表示はどこから？Where do the prices come from?

mempool.space の公開価格（取得できないときは CoinGecko）を使った参考値です。売買の判断には使わないでください。They’re indicative values from mempool.space’s public price feed (CoinGecko as a fallback). Please don’t base trades on them.
