T−5 · KEYGEN

鍵をつくり、札に書く

お使いのウォレットアプリで、このコイン専用の鍵をつくります。札に書く形を選んでください。

  1. ウォレットアプリで、新しいウォレットをつくります。ふだん使いのウォレットとは分けてください。
  2. 表示された12語（復元フレーズ）を、番号をつけて札に書き写します。
  3. 札のすみに、使ったウォレットの名前と、アドレスの種類（bc1q など）も書き添えます。受け取った人が、同じ形で復元できます。

パスフレーズ（追加の合言葉）は付けないでください。付けると、札に書いていない合言葉がなければ復元できません。

  1. このコイン専用の秘密鍵を1つ用意します（WIF形式。5・K・L で始まる文字列）。
  2. 秘密鍵を、札にはっきり書き写します。1文字ちがうだけで、復元できなくなります。
  3. 使ったウォレットの名前も書き添えます。

秘密鍵を読み込める（スイープできる）ウォレットは、12語より限られます。贈るなら、12語がおすすめです。

12語や秘密鍵は、この画面には入力しません。紙に手で書くだけです。写真にも撮らないでください。

T−4 · VERIFY SLIP

札を確かめる

確かめるのは、お使いのウォレットで。このサイトは、確かめるために鍵を求めません。

復元して確かめる方法

まだ入金していないので、試しても失うものはありません。

  2. 出てきた最初の受取アドレスが、手順 T−5 のウォレットと同じなら、札は正しく書けています。
  3. 確かめたら、復元した側のウォレットは削除してかまいません。ふだん使いのウォレットは消さないでください。

違ったときは、書き間違いか、ウォレットの種類（アドレスの形）の違いです。新しい鍵でつくり直すのが確実です。まだ何も書き込んでいないので、やり直せます。

T−3 · ADDRESS LOCK

座標を照合する

T−5 のウォレットの「受け取る」画面から、受取アドレスを貼り付けます。

ウォレットの画面と見比べて、合っていたチップを押してください。

照合 0 / 0

コックピットの上に出ます。

このアドレスはコインに書き込まれ、かざした人は誰でも残高を見られます。動かせるのは、札の鍵を持つ人だけです。

T−2 · NFC UPLINK

NFCに書き込む

コインの中のタグに、このコインのコックピットのURLを書き込みます。

UPLINK URL · 書き込むURL

このブラウザは、NFCへの書き込みに対応していません。Android の Chrome で開くか、「iPhone・その他」の方法で書き込んでください。

NFCに書き込む 押したら、コインをスマホの背面に当てて、そのまま待ちます。NFCの位置は機種によって違います。

コインをいったん離してから押し、もう一度当てます。

ロックすると、だれもこのタグを書き換えられなくなります（偽のページへのすり替えを防げます）。あなた自身も、二度と書き換えられません。ロックしなくても、次へ進めます。

iPhone のブラウザからは、NFCに書き込めません。書き込み用のアプリ（例：NFC Tools）を使います。

  1. アプリで「書き込む（Write）」→「レコードを追加（Add a record）」→「URL / URI」を選びます。
  2. コピーしたURLを貼り付けます。アプリによっては「https://」が先に入っているので、二重にならないように。
  3. 書き込みを押して、コインを iPhone の上部に当てます。
  4. ホーム画面に戻ってコインをかざし、出てきた通知から、コックピットが開くか確かめます。

ロックはアプリの機能で行えます（NFC Tools なら「その他（Other）」→「タグをロック（Lock tag）」）。取り消せません。

T−1 · SEAL

封印する

札を折ってコインに納めます。最後に、封印シールを貼ります。

  • 貼る前に、コインの面のほこりや指の脂をふき取る
  • 台紙から端を持ってはがし、まっすぐ当てる
  • 貼ったら、指で端までしっかり押さえる
封印シールを貼ったら、長押しで封じる 押しつづけると、輪が一周して封じます

  • 入金は、このコインのアドレスへ。ウォレットの「受け取る」画面は、入金のあと別のアドレスに変わることがあります。コインに数えられるのは、このアドレスへの入金だけです。
  • 紋は、最初に承認された入金のブロックで決まります。少額で試しに入金すると、その入金で紋が決まります。
  • 贈るなら、T−5 のウォレットをスマホに残すか決めておきましょう。残せば、あなたも動かせます。消せば、札だけが鍵になります。
