T−5 · KEYGEN

鍵をつくり、札に書くCreate a key, write the slip

お使いのウォレットアプリで、このケース専用の鍵をつくります。札に書く形を選んでください。Use your wallet app to create a key just for this case. Choose what goes on the slip.

  1. ウォレットアプリで、新しいウォレットをつくります。ふだん使いのウォレットとは分けてください。Create a new wallet in your wallet app. Keep it separate from your everyday wallet.
  2. 表示された12語（復元フレーズ）を、番号をつけて札に書き写します。Copy the 12 words (recovery phrase) onto the slip, numbered.
  3. 札のすみに、使ったウォレットの名前と、アドレスの種類（bc1q など）も書き添えます。受け取った人が、同じ形で復元できます。In a corner of the slip, note the wallet’s name and the address type (e.g. bc1q), so whoever receives it can restore it the same way.

パスフレーズ（追加の合言葉）は付けないでください。付けると、札に書いていない合言葉がなければ復元できません。Don’t add a passphrase (an extra word). If you do, the slip alone won’t be enough to restore it.

  1. このケース専用の秘密鍵を1つ用意します（WIF形式。5・K・L で始まる文字列）。Prepare one private key just for this case (WIF format, starting with 5, K or L).
  2. 秘密鍵を、札にはっきり書き写します。1文字ちがうだけで、復元できなくなります。Copy the private key clearly onto the slip. A single wrong character makes it unrecoverable.
  3. 使ったウォレットの名前も書き添えます。Note the wallet’s name as well.

秘密鍵を読み込める（スイープできる）ウォレットは、12語より限られます。贈るなら、12語がおすすめです。Fewer wallets can import (sweep) a private key than a 12-word phrase. For gifts, 12 words are the safer choice.

12語や秘密鍵は、この画面には入力しません。紙に手で書くだけです。写真にも撮らないでください。You never type the 12 words or private key into this page — you only write them by hand. Don’t photograph them either.

T−4 · VERIFY SLIP

札を確かめるVerify the slip

確かめるのは、お使いのウォレットで。このサイトは、確かめるために鍵を求めません。You verify it in your own wallet. This site never asks for the key to check it.

復元して確かめる方法How to verify by restoring

まだ入金していないので、試しても失うものはありません。Nothing has been deposited yet, so there’s nothing to lose by testing.

  2. 出てきた最初の受取アドレスが、手順 T−5 のウォレットと同じなら、札は正しく書けています。If the first receive address matches the wallet from T−5, the slip is correct.
  3. 確かめたら、復元した側のウォレットは削除してかまいません。ふだん使いのウォレットは消さないでください。After checking, you can delete the restored copy. Don’t delete your everyday wallet.

違ったときは、書き間違いか、ウォレットの種類（アドレスの形）の違いです。新しい鍵でつくり直すのが確実です。まだ何も書き込んでいないので、やり直せます。If it doesn’t match, it’s a copying mistake or a different wallet type (address format). Starting over with a new key is the surest fix — nothing has been written yet.

T−5 のウォレットの「受け取る」画面から、受取アドレスを貼り付けます。Paste the receive address from the “Receive” screen of the wallet you made in T−5.

ウォレットの画面と見比べて、合っていたチップを押してください。Compare with your wallet’s screen and tap each chunk that matches.

このアドレスは蓋のタグに書き込まれ、かざした人は誰でも残高を見られます。動かせるのは、札の鍵を持つ人だけです。This address goes onto the lid’s tag, so anyone who taps it can see the balance. Only whoever holds the slip’s key can move it.

T−2 · NFC UPLINK

NFCに書き込むWrite the NFC tag

蓋のNFCタグに、このケースのコックピットのURLを書き込みます。使うのは、無料のアプリ「NFC Tools」（開発元 wakdev）です。Write this case’s cockpit URL to the NFC tag in the lid, using the free app “NFC Tools” by wakdev.

UPLINK URL
  1. App Store で「NFC Tools」（開発元 wakdev）を入れて、開きます。Install “NFC Tools” (developer: wakdev) from the App Store and open it.
  2. 書く（Write）→ レコードを追加（Add a record）→ URL / URI を選びます。Tap Write → Add a record → URL / URI.
  3. コピーしたURLを貼り付けて OK。「https://」が二重になっていないか確かめます。Paste the copied URL and tap OK. Make sure “https://” isn’t doubled.
  4. 書く（Write）を押し、iPhone の上の端（カメラのあたり）を蓋に当てて、完了の表示が出るまで動かしません。Tap Write, then hold the top edge of the iPhone (near the camera) to the lid until it says it’s done.

  1. 設定で NFC をオンにします（「接続」などの項目の中にあります）。Turn NFC on in Settings (usually under Connections).
  2. Google Play で「NFC Tools」（開発元 wakdev）を入れて、開きます。Install “NFC Tools” (developer: wakdev) from Google Play and open it.
  3. 書く（Write）→ レコードを追加（Add a record）→ URL / URI を選び、URLを貼り付けて OK。Tap Write → Add a record → URL / URI, paste the URL and tap OK.
  4. 書く（Write）を押し、スマホの背面（中央〜上のあたり）を蓋に当てて待ちます。Tap Write and hold the back of the phone (center to upper area) to the lid.
