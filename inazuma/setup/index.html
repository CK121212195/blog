封じの手順

あなたの稲妻守を、封じましょう

鍵をつくるのも、封をするのも、あなたの手元だけ。このサイトが扱うのは、公開の受取アドレスだけです。

  1. 1鍵をつくり、札に書くウォレットで、この御守り専用の鍵を
  2. 2札を確かめる書いた札から、同じアドレスになるか
  3. 3アドレスを照合する受取アドレスを、4文字ずつ指で
  4. 4NFCに書き込むかざすと、この御守りのページが開くように
  5. 5銀帯で封じる札を納めて、背面の継ぎ目に銀帯を

用意するもの

  • 稲妻守のキット（御守り・札・銀帯）
  • ウォレットアプリの入ったスマホ
  • 油性の細いペン
  • NFCに書き込めるスマホ（Android は、このページから。iPhone は、書き込み用のアプリで）

手順 1 / 5

鍵をつくり、札に書く

お使いのウォレットアプリで、この御守り専用の鍵をつくります。札に書く形を選んでください。

  1. ウォレットアプリで、新しいウォレットをつくります。ふだん使いのウォレットとは分けてください。
  2. 表示された12語（復元フレーズ）を、番号をつけて札に書き写します。
  3. 札のすみに、使ったウォレットの名前と、アドレスの種類（bc1q など）も書き添えます。受け取った人が、同じ形で復元できます。

パスフレーズ（追加の合言葉）は付けないでください。付けると、札に書いていない合言葉がなければ復元できません。

  1. この御守り専用の秘密鍵を1つ用意します（WIF形式。5・K・L で始まる文字列）。
  2. 秘密鍵を、札にはっきり書き写します。1文字ちがうだけで、復元できなくなります。
  3. 使ったウォレットの名前も書き添えます。

秘密鍵を読み込める（スイープできる）ウォレットは、12語より限られます。贈るなら、12語がおすすめです。

12語や秘密鍵は、この画面には入力しません。紙に手で書くだけです。写真にも撮らないでください。

手順 2 / 5

札を確かめる

確かめるのは、お使いのウォレットで。このサイトは、確かめるために鍵を求めません。

復元して確かめる方法

まだ入金していないので、試しても失うものはありません。

  2. 出てきた最初の受取アドレスが、手順1のウォレットと同じなら、札は正しく書けています。
  3. 確かめたら、復元した側のウォレットは削除してかまいません。ふだん使いのウォレットは消さないでください。

違ったときは、書き間違いか、ウォレットの種類（アドレスの形）の違いです。新しい鍵でつくり直すのが確実です。まだ何も書き込んでいないので、やり直せます。

手順 3 / 5

アドレスを照合する

手順1のウォレットの「受け取る」画面から、受取アドレスを貼り付けます。

ウォレットの画面と見比べて、合っていたチップを押してください。

照合 0 / 0

御守りのページの上に出ます。

このアドレスは御守りに書き込まれ、かざした人は誰でも残高を見られます。動かせるのは、札の鍵を持つ人だけです。

手順 4 / 5

NFCに書き込む

御守りの中のタグに、この御守りのページのURLを書き込みます。

書き込むURL

このブラウザは、NFCへの書き込みに対応していません。Android の Chrome で開くか、「iPhone・その他」の方法で書き込んでください。

NFCに書き込む 押したら、御守りをスマホの背面に当てて、そのまま待ちます。NFCの位置は機種によって違います。

御守りをいったん離してから押し、もう一度当てます。

ロックすると、だれもこのタグを書き換えられなくなります（偽のページへのすり替えを防げます）。あなた自身も、二度と書き換えられません。ロックしなくても、次へ進めます。

iPhone のブラウザからは、NFCに書き込めません。書き込み用のアプリ（例：NFC Tools）を使います。

  1. アプリで「書き込む（Write）」→「レコードを追加（Add a record）」→「URL / URI」を選びます。
  2. コピーしたURLを貼り付けます。アプリによっては「https://」が先に入っているので、二重にならないように。
  3. 書き込みを押して、御守りを iPhone の上部に当てます。
  4. ホーム画面に戻って御守りをかざし、出てきた通知から、御守りのページが開くか確かめます。

ロックはアプリの機能で行えます（NFC Tools なら「その他（Other）」→「タグをロック（Lock tag）」）。取り消せません。

手順 5 / 5

銀帯で、封をする

札を折って引き出しに納め、引き出しを閉じます。背面の継ぎ目をまたぐように、銀帯を貼ります。

  • 貼る前に、継ぎ目のほこりや指の脂をふき取る
  • 台紙から端を持ってはがし、まっすぐ当てる
  • 貼ったら、指で端までしっかり押さえる
銀帯を貼ったら、長押しで封じる 押しつづけると、輪が一周して封じます

これから

  • 入金は、この御守りのアドレスへ。ウォレットの「受け取る」画面は、入金のあと別のアドレスに変わることがあります。御守りに数えられるのは、このアドレスへの入金だけです。
  • 紋は、最初に承認された入金のブロックで決まります。少額で試しに入金すると、その入金で紋が決まります。
  • 贈るなら、手順1のウォレットをスマホに残すか決めておきましょう。残せば、あなたも動かせます。消せば、札だけが鍵になります。
