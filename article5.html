Pythonの「関数」とは？自作するメリットと具体的な書き方

プログラミングを進めていくと、コードの行数が数百行に膨れ上がることがあります。その時、「全く同じ処理を、色々な場所で何度も書いている」ことに気づくかもしれません。

コードの重複を防ぎ、後から読みやすく修正しやすいプログラムを作るための必須テクニックが「関数（かんすう）」です。

関数とは何か？

関数とは、複数の処理をひとまとめにして「名前」をつけたものです。Pythonには、文字を表示する print() や、長さを測る len() などの便利な関数が最初から用意されています（組み込み関数）。

しかし、既存の関数だけでは足りない場合、私たちは自分でオリジナルの関数を作ることができます。

関数を自作するメリット（DRY原則）

プログラミングには「DRY (Don't Repeat Yourself) = 繰り返しを避けよ」という有名な原則があります。

関数を作って処理を共通化しておけば、もし計算式を変更したくなった場合、関数の中身を1箇所修正するだけで済みます。あちこちにコピペしたコードをすべて修正して回る手間とミスを劇的に減らすことができます。

関数の作り方 (def)

Pythonで関数を定義するには、def（defineの略）というキーワードを使います。

基本構文は def 関数名(引数): です。関数に渡すデータのことを「引数（ひきすう）」と呼びます。処理が終わった後、結果を元の場所に返したい場合は return キーワードを使います（これを「戻り値」と呼びます）。

例えば、消費税を計算する関数を作っておけば、金額を引数として渡すだけで、常に正しい税込み価格を戻り値として返してくれるようになります。初心者の方は、まず「3回以上同じコードを書いたら、関数にできないか考える」癖をつけてみましょう。
